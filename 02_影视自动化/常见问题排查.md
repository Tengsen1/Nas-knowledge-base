# 常见问题排查

## 认证失败："用户未绑定合作站点账号"

**原因**：IYUU 账号未绑定任何 PT 合作站点。

**解决**：
1. 注册一个 IYUU 合作 PT 站点
2. 获取该站点的 UID 和 passkey
3. 在 `https://vip.iyuu.cn/app/user/bind` 绑定合作站点
4. 重新在 MoviePilot Web UI 进行 IYUU 认证

## 认证失败："非法请求：缺少必要参数sign"

**原因**：通过 API 传递 sign 参数格式不正确。

**解决**：使用 Web UI 认证，Web UI 能正确传递 sign 参数。

## 环境变量 IYUU_SIGN 报未设置

**原因**：`.so` 编译文件的环境变量读取与 Python `os.environ.get` 行为不一致。

**解决**：不影响 Web UI 认证流程，可忽略此日志警告。

## 媒体服务器 502 Bad Gateway

**原因**：TrimeMedia 模块初始化时序问题。

**解决**：重启 MoviePilot 容器（`docker restart moviepilot-v3`），等待 30 秒后重试。

## 下载文件无法整理转存

**原因**：MoviePilot 容器未挂载 QB 下载目录，或两者挂载路径不一致。

**解决**：确保 QB 和 MoviePilot 的 `/downloads` 指向同一宿主机路径，重新部署容器。

## 做种自动中断 / 魔力值不增长

**原因**：传输方式设为 `move`，文件移动后本地无文件，MoviePilot 自动删除种子。

**解决**：将传输方式改为 `copy`，确保本地保留做种文件。详见 [[PT站点保号策略]]。

## QQ 通知不推送

**原因**：AppID/AppSecret 配置错误，或用户 OpenID 未正确上报。

**解决**：
1. 确认 QQ 开放平台应用状态正常
2. 确认用户已向机器人发过至少一条消息（触发 OpenID 上报）
3. 在 MoviePilot 通知设置中点击"测试"验证连通性
4. 检查 MoviePilot 日志中 QQ Bot 模块连接状态

## QQ 中搜不到机器人

**原因**：QQ 开放平台应用未完成发布上线。

**解决**：登录 QQ 开放平台，检查应用状态，完成发布上线流程。

## M-Team API 调用被 Cloudflare 拦截

**原因**：直接使用 `requests` 库调用 M-Team API 会被 Cloudflare 拦截返回 302。

**解决**：必须在 MoviePilot 容器内通过 `RequestUtils` 调用（自带 Cloudflare 绕过）。

## RequestUtils.post_res 对 JSON POST 返回 None

**原因**：`RequestUtils.post_res` 对 JSON POST 请求存在兼容性问题。

**解决**：调用 MoviePilot API 和 QQ Bot API 时使用原生 `requests` 库。M-Team API 仍需用 `RequestUtils`。

## 容器内脚本重启后丢失

**原因**：脚本写入 `/tmp/` 目录，容器重启后丢失。

**解决**：将脚本和缓存文件持久化到 `/config/scripts/` 目录。

## qBittorrent 容器无法解析 RSS 域名

**原因**：容器内 DNS 配置可能无法解析 PT 站点域名。

**解决**：在 QB 容器的 `custom-cont-init.d` 目录中添加启动脚本，自动写入 hosts 记录。

## M-Team RSS 链接过期

**原因**：M-Team RSS 下载链接有签名有效期。

**解决**：设置 cron 定时任务重新调用 genlink API 生成新 RSS 链接，更新 QB RSS 源 URL。

## qBittorrent v5 API 变更

- 登录成功返回 HTTP 204 空响应 + cookie（`QBT_SID_8080`）
- RSS 端点：`/api/v2/rss/addFeed`、`/api/v2/rss/removeItem`、`/api/v2/rss/setRule`
- `setRule` 需传 `ruleDef` 参数（JSON 格式）
- `setPreferences` 需用 `--data-urlencode "json={...}"`
