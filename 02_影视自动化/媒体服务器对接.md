# 飞牛影视（TrimeMedia）媒体服务器对接

## 对接配置

MoviePilot 原生支持飞牛影视（类型：`trimemedia`），模块代码位于 `/app/app/modules/trimemedia/`。

1. MoviePilot Web UI → 设置 → 媒体服务器
2. 类型选择 飞牛影视（TrimeMedia）
3. 填写飞牛影视 API 地址：`http://<NAS_IP>:<端口>`
4. 填写飞牛影视用户名和密码
5. 保存配置

## 飞牛影视 API 路径

- API 基础路径：`http://host:port/v/api/v1/`
- v2 登录接口：`/api/v2/user/loginByPassword`（SHA256 密码摘要）

## 关键陷阱：502 Bad Gateway

> **保存 TrimeMedia 配置后可能出现 502 Bad Gateway 错误，需重启 MoviePilot 容器让 trimemedia 模块重新初始化。**

**解决方案**：
```bash
echo '<sudo密码>' | sudo -S docker restart moviepilot-v3
```
重启后等待约 30 秒，再测试媒体服务器连接。
